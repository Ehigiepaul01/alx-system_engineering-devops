# Systems Engineering & DevOps Foundations

A collection of systems-engineering exercises covering Linux, shell scripting, processes, permissions, networking, web infrastructure and operational fundamentals.

## Why I am keeping this repository

This repository represents an important part of my systems foundation. The work predates my current cloud-infrastructure focus, but the underlying Linux and systems concepts remain directly relevant to infrastructure engineering.

## Topics represented

- Linux command line and shell usage
- Bash scripting
- File permissions and process management
- System administration fundamentals
- Networking and web infrastructure concepts
- Automation through shell scripts
- Operational troubleshooting

## Position in my cloud-engineering portfolio

This is a **foundation repository**, not a flagship cloud project. My newer projects extend these systems concepts into AWS, Infrastructure as Code, CI/CD, containers and Kubernetes.

## Related portfolio direction

- AWS infrastructure
